# Data analysis on Mouse Breeding

As part of a UNSW research course, the team is constructing secondary research on Mouse Breeding, and methods to optimise them.

This repo contains analysis of public papers and their data sets

Papers involved include (and how they are refered to in within the files):
- [Nature](https://www.nature.com/articles/s41684-023-01213-1)
- [Figshare](https://figshare.com/articles/dataset/Dataset_Proper_micro-environment_alleviates_mortality_in_laboratory_mouse_breeding_induced_by_litter_overlap_and_older_dams_/25040630)
